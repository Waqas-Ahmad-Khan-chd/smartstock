# SmartStock

Smart Inventory and Order Management System

## Project Goal

Manage products, suppliers, inventory, and orders.

## Technology Roadmap

- PostgreSQL
- Node.js and Express
- React
- Git and GitHub
- Docker
- GitHub Actions

## Project Description

SmartStock is a full-stack inventory and order management
system designed to manage products, suppliers, customers,
purchases, sales, inventory and payments.

## Technology Stack

- React
- Vite
- Node.js
- Express.js
- PostgreSQL
- Git

- Docker
- Docker Compose
